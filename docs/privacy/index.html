GroupShare

Privacy Policy

Overview

GroupShare is a Chrome extension that lets you share Tab Groups as a single link. It is designed with a zero data collection architecture. No personal information is collected, transmitted, stored on any server, or shared with any third party.

Data That Never Leaves Your Browser

  • Tab URLs and group metadata are encoded directly into the URL hash fragment. The hash fragment is never sent to any server — it stays entirely in your browser.
  • Passwords (when using the password-protect feature) are used locally to encrypt the link payload using AES-256-GCM. The password itself is never transmitted anywhere.

Local Storage

GroupShare uses chrome.storage.local solely to cache passwords for previously unlocked links, so you don't have to re-enter them. This data:

  • Is stored locally on your device only
  • Is never sent to any server or third party
  • Can be cleared at any time by removing the extension

Permissions Used

  • tabs — Read tab URLs in your selected group to generate the shareable link
  • tabGroups — Read group names and colors so they can be preserved when the recipient opens the link
  • storage — Cache passwords locally for previously unlocked encrypted links

No Tracking

GroupShare does not use any analytics, telemetry, cookies, fingerprinting, or tracking of any kind. There are no user accounts and no sign-up.

No Third-Party Data Sharing

No user data is sold, transferred, or shared with any third party for any purpose — including advertising, data brokering, or profiling.

External Resources

The extension popup loads the Geist Sans font from a CDN (cdn.jsdelivr.net) for styling purposes only. The web decoder page uses Google Favicons API to display site icons. No user data is sent to these services.

Open Source

GroupShare is fully open source. You can audit the entire codebase at github.com/vijay2411/Chrome-Group-Share-Extension-Serverless.
