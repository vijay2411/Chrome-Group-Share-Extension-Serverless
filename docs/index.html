GroupShare

Share Chrome Tab Groups as a single link.
End-to-end encrypted. Completely serverless.

How it works

  • Select a Chrome Tab Group from the extension
  • Generate a shareable link instantly
  • Recipients open all tabs in a named, color-coded group
  • Works without the extension via web decoder

Privacy & Security

  • Optional password protection with AES-256 encryption
  • Zero servers, zero tracking — nobody can see your data
  • Tab data stays in the URL hash — never sent to any server
  • Not even the developer can see what you share
